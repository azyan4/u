# AZYAN — موقع البوابة الرئيسية

موقع ثابت (HTML + CSS + JavaScript) بلا خادم ولا قاعدة بيانات ولا خطوة بناء. العربية (RTL) هي الافتراضية، والإنجليزية بزر AR / EN.

## هيكل الملفات

```
index.html                 الصفحة الرئيسية
gifts/index.html           /gifts        (الهدايا)
flowers/index.html         /flowers      (الورد)
events/index.html          /events       (تنسيقات الحفلات)
advertising/index.html     /advertising  (الدعاية والإعلان)
assets/
  css/styles.css           نظام التصميم: الألوان والمسافات والزوايا والظلال في :root
  js/config.js             بيانات المجالات الأربعة + كل نصوص العربية والإنجليزية
  js/app.js                بناء الصفحات (القالب المشترك) + الترجمة + روابط التواصل
  js/fx.js                 اللوجو المغناطيسي + الجزيئات الذهبية + الأزرار المنجذبة + حديقة الورود والفراشات
  img/logo.png             اللوجو الأصلي بعد قصّ الحواف الشفافة فقط (دون أي تعديل في الشكل)
  img/LOGO-original.png    نسخة من الملف الأصلي
```

صفحات المجالات الأربع هي نفس القالب، تختلف فقط في `data-service` داخل كل `index.html`، وبياناتها كلها في `config.js`.

## التشغيل محليًا

- أسهل طريقة: افتح `index.html` بالنقر المزدوج.
- أو من مجلد المشروع: `python3 -m http.server 8080` ثم افتح http://localhost:8080
- إضافة `?dev` للرابط تُظهر ملاحظات التطوير (البيانات الناقصة) حتى خارج localhost.

## أين تضيف بياناتك (كلها في `assets/js/config.js`)

| المطلوب | الحقل | مثال |
|---|---|---|
| رقم واتساب | `whatsapp` | `'9665XXXXXXXX'` (أرقام فقط، بصيغة دولية، بدون + أو مسافات) |
| إنستغرام | `instagram` | `'https://instagram.com/xxxx'` أو `'xxxx'` |
| تيك توك | `tiktok` | `'https://www.tiktok.com/@xxxx'` أو `'xxxx'` |
| صورة المجال | `image` | ضع الصورة في `assets/img/` بالأسماء `gifts.jpg` و`flowers.jpg` و`events.jpg` و`advertising.jpg` (أو غيّر المسار) |
| الأسماء والأوصاف والنص البديل | `name` / `desc` / `alt` | بالعربية والإنجليزية |
| صورة ولون زر المجال في الرئيسية | `card` / `glow` / `bg` | `assets/img/cards/*.svg` (يمكن استبدالها بصور JPG حقيقية) |
| نصوص الواجهة | `i18n` | مفاتيح مركزية للغتين |
| الألوان | `assets/css/styles.css` | متغيرات `--ivory` `--ink` `--sand` `--stone` `--gold` |

- أي رابط تواصل فارغ يُخفى تلقائيًا عند النشر، ويظهر معطّلًا مع تنبيه في وضع التطوير. لا توجد روابط وهمية.
- إذا لم توجد صورة المجال، تظهر لوحة بديلة بأيقونة المجال (ويظهر 404 في وحدة التحكم حتى تضيف الصورة).

## النشر

المجلد كله موقع ثابت، ارفعه كما هو على Netlify أو Cloudflare Pages أو Vercel أو GitHub Pages (أو أي استضافة عادية). لكل مجال مجلد فيه `index.html`، لذلك تعمل الروابط النظيفة `/gifts` و`/flowers` و`/events` و`/advertising` عند فتحها مباشرة دون إعداد إضافي. اربط نطاقك من لوحة الاستضافة.

## ما تم اختباره (متصفح Chromium فعلي)

- فتح الرئيسية وظهور المجالات الأربعة بالاسمين العربي والإنجليزي.
- كل زر يفتح صفحة المجال الصحيحة، وكل صفحة تُفتح مباشرة (مع الشرطة المائلة وبدونها).
- التبديل بين AR و EN (الاتجاه RTL/LTR والنصوص)، ويبقى محفوظًا عند التنقل ويبقى المستخدم في نفس الصفحة.
- انجذاب الأزرار ثم عودتها لموضعها، وحركة اللوجو المحدودة ثم عودته، وكون طبقة الجزيئات لا تلتقط النقر (`pointer-events: none`).
- عدم وجود تمرير أفقي على عرض 390px، وظهور حلقة Focus بلوحة المفاتيح.
- تعطيل الحركة عند `prefers-reduced-motion`.
- لقطات شاشة للرئيسية (حاسوب وهاتف) وصفحة مجال.

## يحتاج بيانات منك

أرقام واتساب، حسابات إنستغرام وتيك توك لكل مجال، وصور المجالات الأربع. لم يُختبر فتح روابط التواصل لأنها غير مُدخلة بعد، ولم تُجرَّب الصفحات على جهاز لمسي حقيقي (جُرّب فقط التخطيط في وضع محاكاة الهاتف).

## كيف تعدّل بنفسك

1. حمّل برنامج Visual Studio Code (مجاني) من code.visualstudio.com، وافتح مجلد المشروع: File ثم Open Folder.
2. ثبّت إضافة Live Server من قائمة الإضافات، ثم انقر يمين على `index.html` واختر Open with Live Server. كل حفظ (Ctrl+S) يظهر في المتصفح مباشرة.
3. النصوص وأرقام التواصل والصور والأوصاف: `assets/js/config.js`. الألوان والأحجام: `assets/css/styles.css` (أول الملف). عدّل ما بين علامتي الاقتباس فقط، ولا تحذف الفاصلة أو القوس. إن تعطّل الموقع اضغط Ctrl+Z.
